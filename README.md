# Qubic Wallet guides

Documentation for the Qubic desktop wallet, split by task instead of piled into one repository.

- [Setup and accounts](https://github.com/qubic-wallet/qubic-wallet-setup) - install, create, back up, restore
- [Troubleshooting](https://github.com/qubic-wallet/qubic-wallet-troubleshooting) - sync, balance, transactions, fees
- [Features](https://github.com/qubic-wallet/qubic-wallet-features) - assets, QX trading, build status
- [Trust](https://github.com/qubic-wallet/qubic-wallet-trust) - source, release, seed model, comparisons

The wallet itself lives in [qubic-desktop-wallet](https://github.com/qubic-wallet/qubic-desktop-wallet),
with the current release on its releases page.
